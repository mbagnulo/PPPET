Path_indexes is used to indicate in which direction to hash. We use 0 if the current node is on the left (e.g., h3 -> i = 0 -> Poseidon([h3,h4])
and 1 if the current node is on the right (e.g., h34 -> i = 1 -> Poseidon([h12, h34]))

Path indicates the nodes from kp_hs_id to the root ([h4, h12])

The circom implementation of Ed25519 uses a special format in base 2^85 to represent points. We've used utils/point_to_base_2_85.py
to calculate the base 2^85 representation of kp_hs_id.
